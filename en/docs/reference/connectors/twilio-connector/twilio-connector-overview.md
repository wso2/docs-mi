# Twilio Connector Overview

The Twilio connector allows you to connect to [Twilio](http://www.twilio.com/), an online service that lets you embed phones, VoIP, and messaging in web, desktop, and mobile software. The connector uses the Twilio SDK to connect to Twilio and work with accounts, applications, calls, messages, and more. The underlying Java classes in the connector use the [Twilio Java SDK](https://github.com/twilio/twilio-java) to make the HTTP requests to the Twilio API.

Go to the <a target="_blank" href="https://store.wso2.com/connector/esb-connector-twilio">WSO2 Connector Store</a> to download the Twilio connector.

## Compatibility

| Connector Version | Supported product versions             |
|-------------------|----------------------------------------|

| 1.1.0             | MI 4.0.0, MI 4.1.0, MI 4.2.0, MI 4.3.0 |
